# Onboarding photography

The onboarding screen uses three photos from [Pexels](https://www.pexels.com).
The Pexels license allows free commercial use and does not require
attribution, but the sources are recorded here so the images can be traced or
replaced later.

| File | Pexels photo | Used for |
| --- | --- | --- |
| `assets/images/onboarding/guidance.jpg` | [7990373](https://www.pexels.com/photo/7990373/) | Expert guidance slide |
| `assets/images/onboarding/offline.jpg` | [7990382](https://www.pexels.com/photo/7990382/) | Works offline slide |
| `assets/images/onboarding/safety.jpg` | [32951011](https://www.pexels.com/photo/32951011/) | Vaccines & safety slide |

If a photo is replaced, keep the same 9:14 portrait ratio (or update the
`imageAlignment` in `onboarding_page.dart`) and try to keep the file under
~300 KB so the first launch stays quick on low-end phones.
